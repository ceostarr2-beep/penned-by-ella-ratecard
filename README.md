Penned by Ella ✨

Thoughtful Writing. Meaningful Connection.

Penned by Ella is an elegant, responsive website designed for a writing and content communication brand founded by Emmanuella Olong.

The website presents her writing services, monthly packages, introductory rates, and health communication offerings in a refined, easy-to-navigate format.

🌿 About the Project

The goal of Penned by Ella is to help individuals, professionals, and businesses discover writing services that suit their needs and make it easy to enquire about working together.

The design combines warm ivory, rich brown, and subtle champagne gold to create a polished editorial experience.

✨ Features

- Elegant visual identity: A warm, editorial-inspired colour palette and refined typography.
- Responsive design: Layouts adapted for mobile phones, tablets, and desktop screens.
- Writing services: Individual service listings with introductory prices.
- Monthly packages: Basic, Standard, and Premium plans with clearly outlined deliverables.
- WhatsApp enquiries: Package buttons prepare messages containing the selected service and price.
- Contact form: Collects project details and prepares an enquiry for WhatsApp.
- Interactive experience: Smooth scrolling, subtle animations, and hover effects.
- Accessibility considerations: Semantic HTML and reduced-motion support.
- SEO foundations: Page title, meta description, and mobile-friendly structure.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/penned-by-ella.git

Replace "YOUR-USERNAME" with your GitHub username.

2. Open the project

Open "index.html" in a browser or use Acode on Android to preview and edit the website.

3. Add the portrait

Place Emmanuella's approved portrait in the project root and name it:

emmanuella.jpg

4. Configure WhatsApp

Open "index.html" and find the "WHATSAPP_NUMBER" constant in the JavaScript section.

Replace the example number with the correct WhatsApp number, including the country code and excluding the plus sign, spaces, and dashes.

5. Deploy with GitHub Pages

1. Push the project files to your GitHub repository.
2. Open Settings → Pages.
3. Select deployment from a branch.
4. Choose your main branch and the root folder.
5. Save and open the published website URL once deployment is complete.
